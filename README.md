# BANANOS Manager

Sistema de punto de venta con inventario, mesas, caja, usuarios y reportes PDF, desarrollado con FastAPI y SQLAlchemy.

## Funciones

- Ventas rápidas y cuentas por mesa.
- Gestión de productos, existencias y preparaciones.
- Usuarios, apertura y cierre de caja, estadísticas y reportes PDF.

## Tecnologías

Python, FastAPI, SQLAlchemy, JWT, HTML, CSS, JavaScript y Docker.

## Inicio local

```bash
docker compose up --build
```

http://localhost:8001

## Configuración y alcance

Versión de código seleccionada: V3.4. El arranque crea usuarios de demostración admin/admin123 y vendedor/venta123. Cambiar estas contraseñas y configurar SECRET_KEY antes de utilizar datos reales. Esta copia no incluye la base de datos ni imágenes cargadas por usuarios.
